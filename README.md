# Auditoria de tokens

Base da auditoria de custo de modelo da Vortex. Números de exemplo, sem dado de cliente.

- `front/` é Vite.
- `back/` é Nest.

## Rodar

```bash
cd back && npm install && npm run start:dev
cd front && npm install && npm run dev
```

A tela abre em http://127.0.0.1:4180. As chamadas de `/api` vão para o back em 4181.
